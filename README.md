# Vastra — AI Personal Stylist

A full-stack web app that generates personalized outfit recommendations using AI, with direct shopping links to Amazon, Flipkart, Meesho, and Ajio.

**Live demo:** https://vastra-frontend.onrender.com

## Features
- User authentication (signup/login) with JWT
- AI-generated outfits based on style, occasion, weather, budget, and gender filters
- Shopping links to 4 major Indian e-commerce platforms per item
- Persistent per-user outfit history
- Custom dark-themed React interface

## Tech Stack
- **Frontend:** React, Vite, Tailwind CSS
- **Backend:** Node.js, Express, MongoDB (Mongoose)
- **AI:** Google Gemini API
- **Auth:** JWT, bcrypt
- **Deployment:** Render (backend + frontend), MongoDB Atlas
